## Projetos e tecnologias

Este repositório reúne atividades práticas de engenharia e análise de dados, organizadas por sprint. Os projetos incluem automação de processamento de arquivos e geração de relatórios, modelagem e normalização de dados relacionais, limpeza e consulta de conjuntos de dados e construção de um fluxo de ingestão e análise de dados na AWS.

No projeto final, dados de filmes, séries e artistas foram obtidos da API TMDB e armazenados no Amazon S3. O trabalho envolveu processamento e consulta dos dados com ferramentas do ecossistema AWS, organização de tabelas para análise, criação de métricas para avaliar artistas e produção de um dashboard no Power BI.

### Tecnologias utilizadas

- **Linguagens e análise:** Python, SQL, pandas e NumPy.
- **Dados e processamento:** modelagem relacional, normalização, limpeza de dados, Apache Spark e AWS Glue.
- **AWS:** Amazon S3, AWS Lambda, Amazon Athena e S3 Select; integração com serviços usando boto3.
- **Desenvolvimento e execução:** Docker e Docker Compose.
- **Visualização:** Power BI.
