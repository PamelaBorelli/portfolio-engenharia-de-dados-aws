Escreva uma função que recebe uma string de números separados por vírgula e retorne a soma de todos eles. Depois imprima a soma dos valores.



A string deve ter valor  "1,3,4,6,10,76"

# Função que recebe a string com números, transforma em inteiros e faz a soma
def soma_numeros(string_numeros):
    numeros = string_numeros.split(',')
    soma = sum(int(numero) for numero in numeros)
    return soma

# Variável que recebe a string
string_numeros = "1,3,4,6,10,76"
# print do resultado da função
print(soma_numeros(string_numeros
